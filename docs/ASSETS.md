# Asset gap list

Everything on the page today is a real SeoulCeuticals asset taken from seoulceuticals.com (product packshots,
the About page renders and ingredient still life, campaign portraits, the red serum-gel texture, the cream texture
and the logo). Nothing was generated. These are the gaps that would lift the page further.

## Needed for launch quality

| Asset | Where it goes | Why |
|---|---|---|
| Ritual step 3 art: Snail Repair Cream in the same macro style as `sc-ritual-step-1/2.png` | Daily ritual, step 03 | The live `sc-ritual-step-3.png` shows **Snail Eye Cream** while naming Snail Repair Cream. We use the clean packshot instead. |
| Higher-resolution ritual art (≥1400 px wide) | Daily ritual steps 01 and 02 | The live files are 693 × 560, which softens at 2× DPR on large screens. |
| Packshots on one neutral, consistent backdrop for all five flagship products | Flagship line, concern panels | The current blush backdrops work, but a single studio set would make the grid feel fully art-directed. |
| Ingredient macro photography: snail mucin, PDRN, centella, ginseng, rice bran | Formula chapter annotations, Philosophy | The Formula chapter uses abstract droplets because no ingredient macros exist. |
| Skin macro campaign imagery (diverse, unretouched-looking) | Philosophy "Fig. 02 · Skin", Closing | The brief's "Skin" world currently relies on one campaign portrait. |
